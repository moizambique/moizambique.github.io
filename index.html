The Problem

Manual endurance testing for the HeartMate Touch Monitor — a Class III life-sustaining cardiac device — required a technician to physically monitor the device, log data by hand, and reset tests every few hours. Overnight testing was impossible, creating a 16-hour daily dead zone in the validation schedule.

The Cost of Manual Testing

Without automation, each 72-hour validation cycle would have required approximately 240 technician-hours over 10 days. At a blended engineering rate, that is roughly $36,000 per cycle in labor alone — not counting schedule delays that would push back FDA submission timelines and ultimately delay getting life-saving technology to patients.

The Solution

I designed and deployed a 5-fixture automation ecosystem using Arduino Mega, precision relay control boards, color sensor feedback algorithms, and adaptive battery detection firmware. The system runs fully unattended for 72+ hours with real-time LCD status prompts and Python-based automated test sequencing, logging, and anomaly detection.
